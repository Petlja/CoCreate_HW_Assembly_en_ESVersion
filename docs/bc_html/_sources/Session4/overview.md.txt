El montaje de computadoras es una tarea esencial de un técnico de instalación de computadoras. Es un proceso en el que se ensamblan todos los componentes internos necesarios para que el sistema informático sea funcional. Hay una secuencia adecuada de fijación para cada componente en el sistema de computadora.

Es un proceso sistemático. Comienza organizando las partes de la computadora.

 Materiales requeridos:

- Carcasa de computadora con fuente de alimentación instalada
- Placa base
- CPU
- Ensamblaje de disipador de calor/ventilador
- Compuesto térmico
- Módulo(s) de RAM
- Separadores y tornillos para la placa base
- Pulsera y alfombrilla antiestática
- Kit de herramientas
